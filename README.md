# 🎲 Tenzies

A fun, interactive dice game built with **React** and powered by **Vite**.

## 🎮 How to Play

**Objective:** Roll until all dice are the same!

1. Click the **Roll** button to roll the 10 dice.
2. Click on individual dice to **freeze** (hold) them at their current value between rolls.
3. Keep rolling the remaining unfrozen dice until all 10 dice display the exact same number.
4. Celebrate your win and click **New Game** to play again!

## ✨ Features

* **Interactive Dice Holding:** Click any die to lock or unlock its value.
* **Win Detection:** Automatically detects when all dice match and are held.
* **Fast Performance:** Built with React and bundled using Vite for instant load times and smooth gameplay.

## 🛠️ Tech Stack

* **React** – UI components and game state management
* **Vite** – Next-generation frontend tooling and dev server
* **CSS** – Styling and responsive grid layout

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your system.

### Installation & Running with Vite

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ahmedhalima/tenzies.git
   cd tenzies
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the Vite development server:**
   ```bash
   npm run dev
   ```

4. **Open in your browser:**
   Vite will output a local URL in your terminal (usually `http://localhost:5173`). Open that link in your browser to start playing!

## 📦 Building for Production

To create an optimized production build using Vite, run:

```bash
npm run build
```

You can preview the production build locally with:

```bash
npm run preview
```
